## DESIGN PRODUCTION NOTES

### Canva workflow (recommended order)
1. Set up Brand Kit in Canva with the colors and fonts above
2. Create Image 1 first — it's the most important
3. Export all at 2700×2025px, JPEG, quality 90%+
4. Test Image 1 thumbnail at small size before finalizing

### File naming for Etsy upload
```
01_Hero_365_Captions_Estheticians.jpg
02_Product_Preview_Inside.jpg
03_Sample_Captions_Preview.jpg
04_Content_Breakdown_Pillars.jpg
05_Compatibility_Formats.jpg
06_Before_After_Time_Saved.jpg
```

### Things to avoid
- Pink, rose gold, or pastel color palettes (signals "hobby seller")
- Stock photos of random women holding phones
- Canva template designs recognizable as defaults
- Cluttered layouts with too much text
- Comic Sans, script fonts, or overly decorative typefaces
- Watermarks on preview images — they reduce trust

### Things that convert
- Dark backgrounds standing out against Etsy's white search page
- Gold accents that communicate premium positioning
- Actual caption text shown (buyers read it and self-qualify)
- Clean, breathing layouts with clear hierarchy
- One primary message per image
