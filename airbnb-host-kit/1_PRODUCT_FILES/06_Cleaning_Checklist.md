## BEFORE YOU START

- [ ] Confirm check-out time with host
- [ ] Bring all supplies (see Supply List at end)
- [ ] Check for guest belongings left behind — set aside in a bag, photo + notify host immediately
- [ ] Open all windows briefly to air out property
- [ ] Start laundry (strip beds first — get washer running before cleaning)
- [ ] Note any damage, stains, or issues — photograph and report to host

---

## LAUNDRY (START FIRST)

- [ ] Strip all beds — sheets, pillowcases, duvet covers
- [ ] Collect all used towels from bathrooms and put in wash
- [ ] Start first load in washer
- [ ] Move to dryer when done — never leave in washer
- [ ] Make beds with fresh linens before leaving

**Linen sets location:** [Location in property]
**Laundry settings:** [Cold/warm, gentle/normal — specify for delicate items]

## KITCHEN

**Countertops & Surfaces:**
- [ ] Wipe all countertops — remove crumbs, stains, residue
- [ ] Wipe down backsplash if splattered
- [ ] Clean sink — scrub, remove food debris, wipe exterior
- [ ] Clean faucet and handles

**Appliances:**
- [ ] Stovetop — remove grates if needed, clean burner areas, wipe surface
- [ ] Oven — wipe interior if used (use oven cleaner if needed)
- [ ] Microwave — clean interior, exterior, and turntable
- [ ] Coffee maker — empty used pods/grounds, wipe exterior, run cleaning cycle if needed
- [ ] Toaster — empty crumb tray, wipe exterior
- [ ] Refrigerator — remove any guest food, wipe interior shelves if needed, clean exterior + handle
- [ ] Dishwasher — run if needed, empty, wipe door interior

**Dishes & Utensils:**
- [ ] All dishes washed, dried, and put away
- [ ] Confirm all items from inventory are present (use Property Inventory Checklist)
- [ ] Pots and pans clean and in proper storage

**Floors:**
- [ ] Sweep kitchen floor
- [ ] Mop kitchen floor (pay attention to under table and near stove)

**Trash:**
- [ ] Remove kitchen trash bag — replace with new bag
- [ ] Clean trash can interior and exterior if dirty
- [ ] Take all trash to outdoor bins

**Restock:**
- [ ] Dish soap
- [ ] Sponge / scrubber (replace if worn)
- [ ] Paper towels
- [ ] Trash bags
- [ ] Coffee/tea (if provided)
- [ ] [Any other pantry items host restocks between guests]

## FINAL WALKTHROUGH

Before leaving, do a full walk-through and check each item:

**Visuals:**
- [ ] All rooms look clean, fresh, and welcoming
- [ ] Bed linens are crisp and properly tucked
- [ ] Towels are neatly folded and placed on beds or in bathrooms
- [ ] No streaks on mirrors
- [ ] No crumbs or residue on kitchen surfaces
- [ ] No hair in bathrooms or on floors

**Functionality:**
- [ ] All lights work (replace bulbs if needed — extras: [location])
- [ ] Thermostat set to [temperature]
- [ ] A/C or heat in standby mode
- [ ] All windows closed and locked
- [ ] Front door locked
- [ ] Lockbox key in lockbox, code scrambled / Smart lock secure

**Guest Experience Touches:**
- [ ] Welcome note / card in place [location]
- [ ] Welcome book placed on [kitchen counter / coffee table]
- [ ] Fresh flowers / candle / amenity: [optional extras if host provides]

**Report to host:**
- [ ] Any damage or stains (with photo)
- [ ] Any items running low or needing replacement
- [ ] Any guest belongings left behind
- [ ] Anything unusual noticed in the property
