# Airbnb Host Starter Kit
## Product README — Version 1.0.0

---

## WHAT THIS IS

The Airbnb Host Starter Kit is a complete operating system for short-term rental hosts — built for people who want to run a professional, profitable hosting business, not spend their weekends reinventing processes from scratch. It is a practical toolkit of SOPs, tracking systems, guest documents, and communication templates that give you the infrastructure of an experienced host from day one.

This is not a PDF with tips. It is a system you implement once and run indefinitely.

## HOW TO GET STARTED

**Step 1:** Open `00-quick-start/QUICK-START-GUIDE.md` and complete all five steps — takes 10 minutes.

**Step 2:** Build your Notion workspace using `05-notion-workspace/NOTION-WORKSPACE-OVERVIEW.md` as the build guide — takes 45–90 minutes.

**Step 3:** Load your 14 message templates into Airbnb Saved Messages (go to Airbnb inbox → Saved Messages → Create New) — takes 20–30 minutes.

After that, start with whichever document matches your immediate situation — launching a new listing, preparing for a guest, or setting up your pricing. The Quick Start Guide has a routing table.
