# Property Setup Master Checklist
## From Empty Property to Live Listing

---

This checklist covers every physical, digital, and administrative step to take a property from unfurnished/unregistered to a live Airbnb listing that can earn 5-star reviews from night one. Work through it in order. Check off each item only when fully complete — not "in progress."

---

## PHASE 1: LEGAL & ADMINISTRATIVE

- [ ] **1.1** Confirm short-term rental is legal in your municipality — check local council planning regulations
- [ ] **1.2** Obtain short-term rental licence if required (varies: Spain, Portugal, France, Italy all require registration)
- [ ] **1.3** Register property for local tourist tax if applicable (collect and remit per booking)
- [ ] **1.4** Notify mortgage lender if property is mortgaged — some lenders prohibit STR without consent
- [ ] **1.5** Notify building management/strata if applicable — check lease or HOA agreements
- [ ] **1.6** Purchase short-term rental specific insurance policy (NOT standard home insurance — it will not cover STR claims)
- [ ] **1.7** Set up a separate bank account for STR income and expenses
- [ ] **1.8** Register as a self-employed host for tax purposes (consult local accountant)
- [ ] **1.9** Obtain EPC (Energy Performance Certificate) if required in your country
- [ ] **1.10** Install and test smoke detectors in every room (minimum: bedroom, living area, kitchen)
- [ ] **1.11** Install CO detector if property has gas appliances or enclosed garage
- [ ] **1.12** Obtain Gas Safety Certificate (annual, if UK-based or gas appliances present)
- [ ] **1.13** Ensure electrical wiring has been tested within the last 5 years (EICR certificate)
- [ ] **1.14** Document and photograph property condition before first guest (timestamped photos for insurance)

## PHASE 2: PHYSICAL PROPERTY SETUP

### 2A — Bedroom(s)

- [ ] **2.1** Mattress: hotel-quality (minimum 180-night-rated); memory foam or pocket-sprung recommended
- [ ] **2.2** Mattress protector: waterproof, fitted, white (2 per bed minimum — one on, one spare)
- [ ] **2.3** Duvet: 10.5 tog (or seasonal: 4.5 tog summer + 9 tog winter available in cupboard)
- [ ] **2.4** Duvet covers: crisp white, 100% cotton or high-quality microfibre (minimum 3 sets per bed)
- [ ] **2.5** Pillows: 2 per person the bed sleeps (4 for a double, 6 for king) + 2 decorative
- [ ] **2.6** Pillow protectors: 1 per pillow (washable)
- [ ] **2.7** Fitted sheet sets: 3 complete sets per bed
- [ ] **2.8** Additional throw blanket: folded at foot of bed
- [ ] **2.9** Bedside table(s): minimum 1 per person, with drawer
- [ ] **2.10** Bedside lamp(s): warm light (2700K), dimmable preferred
- [ ] **2.11** USB charging ports or universal adaptor at each bedside
- [ ] **2.12** Full-length mirror (at least one per property)
- [ ] **2.13** Wardrobe with minimum 10 hangers, spare blanket on shelf
- [ ] **2.14** Blackout curtains or blinds (essential for guest sleep quality)
- [ ] **2.15** Luggage rack or luggage space in wardrobe

### 2B — Bathroom(s)

- [ ] **2.16** Bath towels: minimum 2 per guest capacity (e.g., 4 for a 2-guest property), 3 sets total
- [ ] **2.17** Hand towels: 2 per bathroom, 3 sets
- [ ] **2.18** Face cloths: 2 per bathroom, 3 sets
- [ ] **2.19** Bath mat: non-slip, 2 per bathroom (one in use, one spare)
- [ ] **2.20** Shower head: powerful pressure — replace if flow is weak
- [ ] **2.21** Shower curtain (if applicable): clean, fresh for new guests
- [ ] **2.22** Mirror with good lighting above sink
- [ ] **2.23** Toilet brush and holder (discreet)
- [ ] **2.24** Bin with lid
- [ ] **2.25** Hair dryer: 2000W minimum, mounted or in drawer
- [ ] **2.26** Shampoo, conditioner, body wash (hotel-size or pump dispensers — not half-used bottles)
- [ ] **2.27** Hand soap (liquid, pump)
- [ ] **2.28** Toilet paper: 3 rolls visible per bathroom (guests hate searching)
- [ ] **2.29** Spare toilet rolls in clearly labelled cupboard
- [ ] **2.30** Cotton buds, nail file, shower cap in small basket

### 2C — Kitchen

- [ ] **2.31** Refrigerator: clean, empty, deodorised (leave box of bicarbonate inside)
- [ ] **2.32** Oven/hob: fully functional, clean, with all knobs present
- [ ] **2.33** Microwave
- [ ] **2.34** Kettle (electric, minimum 1.7L)
- [ ] **2.35** Coffee maker (filter or pod — minimum Nespresso or French press)
- [ ] **2.36** Toaster (2-slice minimum)
- [ ] **2.37** Full set of pots (small, medium, large saucepan + frying pan)
- [ ] **2.38** Baking tray and oven dish
- [ ] **2.39** Full cutlery set for max guest count + 2 extra settings
- [ ] **2.40** Full dinner plate set (plates, bowls, side plates) for max guests + 2 extra
- [ ] **2.41** Glasses: wine glasses (2 per guest), water glasses (2 per guest), mugs (2 per guest + 2 extra)
- [ ] **2.42** Chopping board (1 wood, 1 plastic)
- [ ] **2.43** Sharp kitchen knife set (minimum chef's knife, bread knife, paring knife)
- [ ] **2.44** Colander, grater, peeler, can opener, bottle opener, corkscrew
- [ ] **2.45** Wooden spoons, spatulas, ladle, tongs, whisk
- [ ] **2.46** Salt, pepper, olive oil, sugar (starter stock — clearly labelled)
- [ ] **2.47** Coffee pods/capsules (6), tea bags (assorted, 8+), sugar, milk UHT (1 small carton)
- [ ] **2.48** Dish soap, sponges (2 new), dishcloths (3)
- [ ] **2.49** Dishwasher tablets (15) if dishwasher present
- [ ] **2.50** Bin: kitchen bin with lid, foot pedal, with bags fitted and 5 spare bags
- [ ] **2.51** Recycling bins clearly labelled with local recycling rules posted above
- [ ] **2.52** Dish rack or dishwasher
- [ ] **2.53** Kitchen roll holder with full roll

### 2D — Living Area

- [ ] **2.54** Sofa seating for max guest count
- [ ] **2.55** Coffee table
- [ ] **2.56** TV: 40-inch minimum, smart TV with Netflix/Prime/BBC iPlayer
- [ ] **2.57** TV remote: tested, fresh batteries
- [ ] **2.58** WiFi router: prominently placed, strong signal throughout property
- [ ] **2.59** WiFi network name and password displayed visibly (card or frame on coffee table)
- [ ] **2.60** Board games or cards (at least 2 options)
- [ ] **2.61** Adequate lighting (overhead + ambient lamp minimum)
- [ ] **2.62** Hooks near entrance for coats and bags
- [ ] **2.63** Full-length mirror near entrance

### 2E — Utility & Extras

- [ ] **2.64** Washing machine: instructions card taped inside lid or adjacent
- [ ] **2.65** Laundry detergent pods (6 starter supply)
- [ ] **2.66** Ironing board and iron
- [ ] **2.67** Clothes airer/drying rack
- [ ] **2.68** Vacuum cleaner: working, bag/canister empty for each new guest
- [ ] **2.69** Mop and bucket
- [ ] **2.70** Cleaning products stored in accessible cupboard (multi-surface, bathroom cleaner, bleach)
- [ ] **2.71** First aid kit: plasters, antiseptic wipes, paracetamol, antihistamine, bandage
- [ ] **2.72** Umbrella (1 per 2 guests)
- [ ] **2.73** Maps or local area booklet (see Guest Portal documents)

## PHASE 3: SMART HOME & ACCESS

- [ ] **3.1** Smart lock installed and tested (Yale, Nuki, Igloohome, or equivalent)
- [ ] **3.2** Smart lock paired to phone app
- [ ] **3.3** Guest code generation tested — create, send, expire code flow confirmed
- [ ] **3.4** Physical key lockbox installed outside as backup (combination set, not branded)
- [ ] **3.5** Entry instructions documented and tested by someone unfamiliar with the property
- [ ] **3.6** Noise monitor installed in common area (Minut or NoiseAware) — disclosed in listing
- [ ] **3.7** Smart thermostat or clear heating instructions posted
- [ ] **3.8** WiFi extender installed if any dead zones exist in property
- [ ] **3.9** Outdoor security camera (entrance only — NOT inside property; disclose in listing)
- [ ] **3.10** Doorbell (smart or standard) tested and working

## PHASE 4: DIGITAL SETUP

- [ ] **4.1** Airbnb host account verified (government ID, phone, bank account)
- [ ] **4.2** Property address confirmed and map pin accurate on listing
- [ ] **4.3** Professional photographs taken (20–35 images, all rooms, natural light)
- [ ] **4.4** Listing title written using keyword-rich formula (see SOP-01)
- [ ] **4.5** Listing description written — all 5 sections complete (see SOP-01)
- [ ] **4.6** House rules configured on Airbnb (see HOUSE-RULES.md)
- [ ] **4.7** Check-in/check-out times set (recommend: 15:00 check-in, 11:00 check-out)
- [ ] **4.8** Cleaning fee set (see PRICING-STRATEGY-PLAYBOOK.md)
- [ ] **4.9** Security deposit configured (recommend: €150–€300)
- [ ] **4.10** Minimum stay set correctly per season (see PRICING-STRATEGY-PLAYBOOK.md)
- [ ] **4.11** Cancellation policy selected (recommend: Moderate for new hosts)
- [ ] **4.12** Instant Book enabled (increases bookings significantly)
- [ ] **4.13** All 14 Airbnb saved messages loaded (see Section 04)
- [ ] **4.14** Notification settings configured — mobile alerts for all new messages
- [ ] **4.15** Payout method confirmed — first test payout verified

---

## PHASE 5: PRE-LAUNCH QUALITY CHECK

- [ ] **5.1** Do a solo guest walkthrough — enter with your phone as if you're a guest arriving
- [ ] **5.2** WiFi connects immediately on first attempt
- [ ] **5.3** All appliances turn on and function correctly
- [ ] **5.4** Hot water available within 60 seconds
- [ ] **5.5** Property is at correct room temperature (18–21°C in winter, ventilated in summer)
- [ ] **5.6** No odd smells (dampness, cleaning chemicals, pets)
- [ ] **5.7** All lights work
- [ ] **5.8** Blackout curtains block light completely in bedroom
- [ ] **5.9** All locks function correctly
- [ ] **5.10** Listing photos match current property condition
- [ ] **5.11** Welcome guide printed or digital QR code to Guest Portal works
- [ ] **5.12** Ask a trusted friend or family member to review the listing cold — act on feedback
