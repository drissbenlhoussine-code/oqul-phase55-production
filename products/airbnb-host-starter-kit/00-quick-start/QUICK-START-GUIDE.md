# Airbnb Host Starter Kit — Quick Start Guide
## What To Do In Your First 10 Minutes

---

**Before anything else:** This kit is your operating system. Do not read it cover to cover — execute it in sequence. Start here, then follow the numbered path.

---

### STEP 1 — Orient yourself (2 minutes)

Open `PRODUCT-MAP.md` in your root folder. Read the file list once. You now know where everything lives. Bookmark that file — it's your index for the next 90 days.

---

### STEP 2 — Define your property baseline (3 minutes)

Answer these five questions in a notes file right now:

1. **Property address:** ___________________________________
2. **Number of bedrooms / bathrooms / max guests:** ___ / ___ / ___
3. **Nightly rate you're currently listing (or planning):** €___
4. **Your current occupancy rate (or target if launching):** ___%
5. **Your primary goal:** Monthly income target €___ by [Month/Year]

These answers feed directly into your Financial Model (Section 01) and KPI Dashboard (Section 03). Without them, the templates are empty forms. With them, every document becomes a live operating system.

---

### STEP 3 — Set up your Notion workspace (3 minutes to start, 45 minutes to build)

Open `05-notion-workspace/NOTION-WORKSPACE-OVERVIEW.md`. Follow the build guide in exact order:

1. Create a new Notion page: **"[Your Property Name] — Host HQ"**
2. Build the five databases in the order listed (Bookings → Guests → Tasks → Expenses → Maintenance)
3. Link each database to your Command Center page using the property linking system described

Do not skip the database build. Your tracker tabs in Section 03 map 1:1 to Notion databases. Build once, track forever.

---

### STEP 4 — Load your first three SOPs into the Task database (2 minutes)

From `02-sops-and-checklists/`, add these three SOPs as Notion pages inside your Tasks database immediately:

- `SOP-04-TURNOVER-CLEANING.md` — assign to: Yourself or cleaner
- `SOP-03-PRE-ARRIVAL-PREP.md` — assign to: Yourself
- `SOP-05-CHECK-IN-PROCESS.md` — assign to: Yourself

Tag each with Status: **Template**, Repeat: **Every Booking**. These three SOPs run on every single reservation. They go in first.

---

### STEP 5 — Copy your first three message templates into Airbnb Saved Messages (1 minute)

Go to your Airbnb host account → Inbox → Saved Messages → Create New.

Copy these three templates first (they cover your first 72 hours with any new guest):

1. `MSG-01-BOOKING-CONFIRMATION.md` — save as "✅ Booking Confirmed"
2. `MSG-03-CHECKIN-INSTRUCTIONS.md` — save as "🔑 Check-In Instructions"
3. `MSG-07-REVIEW-REQUEST.md` — save as "⭐ Review Request"

Fill in your property's specific details (address, key code, WiFi, etc.) once. Every future guest gets the same professional, complete communication with zero rewriting.
