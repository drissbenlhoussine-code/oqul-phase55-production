# Quick Start Guide
## Airbnb Host Starter Kit · First 10 Minutes

---

**Read this page first. Open nothing else until you finish Step 5.**

---

**STEP 1 — Write down your five baseline numbers. (2 minutes)**

Open a notes file and answer these five questions. Every financial projection in this kit requires them.

1. Property address: ________________________________
2. Bedrooms / Max guests: _______ / _______
3. Your current or target nightly rate: €_______
4. Your current occupancy rate (or target if launching): _______%
5. Monthly net income target: €_______

Without these numbers, the financial model, KPI dashboard, and pricing playbook are empty shells. With them, every document becomes specific to your property.

---

**STEP 2 — Load the 14 message templates into Airbnb Saved Messages. (5–8 minutes)**

Go to: Airbnb.com → Inbox → Saved Messages → Create New.

Create one saved message per template in `04-communication-templates/`. Name each one exactly as listed:

```
✅ Booking Confirmed
📋 Pre-Arrival Info
🔑 Check-In Instructions
👋 Mid-Stay Check-In
🧳 Checkout Reminder
🙏 Post-Checkout Thanks
⭐ Review Request
🔧 Issue Response
🔇 Noise Warning
💬 Inquiry Response
🚫 Soft Decline
🏠 Long-Stay Welcome
🌟 5-Star Review Response
📝 Negative Review Response
```

Before saving each one: replace [PROPERTY NAME], [WIFI PASSWORD], [ACCESS CODE], and [HOST PHONE] with your actual details. This takes 20–30 minutes total. You will use these 14 messages on every booking for the next 3 years.

---

**STEP 3 — Add the 10 recurring SOPs to your task system. (3 minutes)**

Open `02-sops-and-checklists/SOP-10-MONTHLY-HOST-REVIEW.md` last — start with SOP-01.

In whatever task system you use (Notion, Trello, Google Tasks, paper), create 10 recurring tasks named:

```
[Every booking] SOP-03: Pre-Arrival Prep
[Every booking] SOP-04: Turnover Cleaning
[Every booking] SOP-05: Check-In Process
[Every booking] SOP-06: During-Stay Monitoring
[Every booking] SOP-07: Checkout + Damage Review
[Every booking] SOP-09: Review Collection
[Monthly] SOP-10: Monthly Host Review
[Quarterly] SOP-05 Audit: Test your own check-in cold
[Quarterly] Pricing Review: Run Competitor Analysis table
[Annually] Listing Refresh: Photos, description, title
```

These are the only recurring tasks that matter. Everything else is triggered by these.

---

**STEP 4 — Build the tracking spreadsheet first tab. (5 minutes)**

Open Google Sheets. Create a new file named: `[Property Name] — Host Operations 2026`

Build TAB-01 (Revenue Tracker) now. The spec is in `03-tracking-dashboards/TAB-01-REVENUE-TRACKER.md`. Enter the column headers. Enter the three example rows from the spec to verify your formulas work. Delete the example rows.

Build the remaining 6 tabs over the next 7 days as bookings arrive. TAB-01 is the one you need immediately.

---

**STEP 5 — Route yourself to the right first document. (30 seconds)**

| Your situation right now | Open this first |
|---|---|
| No listing yet — launching from scratch | `SOP-01-LISTING-CREATION.md` |
| Listing live, no bookings yet | `05-PLATFORM-OPTIMIZATION-GUIDE.md` |
| Booking confirmed, guest arriving this week | `SOP-03-PRE-ARRIVAL-PREP.md` |
| Just got a 4-star review and don't know why | `04-GUEST-EXPERIENCE-STANDARDS.md` |
| Setting prices for the next 90 days | `02-PRICING-STRATEGY-PLAYBOOK.md` |
| Building your Notion workspace | `05-WORKSPACE-OVERVIEW.md` |
| Want the 90-day Superhost plan | `BONUS-SUPERHOST-90DAY-SPRINT.md` |

---

**You are now ready to use the Airbnb Host Starter Kit.**

Full system setup time: 4–6 hours.
Time saved per booking once operational: 45–90 minutes.
