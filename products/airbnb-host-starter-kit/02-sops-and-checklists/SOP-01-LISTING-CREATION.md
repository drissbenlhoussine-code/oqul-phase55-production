# SOP-01: Listing Creation
## Standard Operating Procedure — Creating a New Airbnb Listing

**Run time:** 4–6 hours  
**Trigger:** New property to list on Airbnb  
**Owner:** Host / Property Manager  
**Prerequisites:** Professional photos ready, property fully set up per PROPERTY-SETUP-MASTER-CHECKLIST.md

---

## STEP 1: Account Setup (skip if existing host)

1.1 Go to airbnb.com/host/homes → click "Create a new listing"  
1.2 Verify host account: government ID, profile photo, phone number, bank account (payout)  
1.3 Set profile bio — write 3–4 sentences: who you are, why you host, your response style, one personal fact that builds trust  
1.4 Upload professional profile photo (clear headshot, smiling, good lighting — guests 23% more likely to book from hosts with real photos)

---

## STEP 2: Property Type & Basic Info

2.1 Select: Entire place / Private room / Shared room (select Entire place for maximum revenue)  
2.2 Select property type: Apartment / House / Guesthouse / Villa / Studio (choose most accurate)  
2.3 Enter exact address — verify the map pin drops in the correct location; drag if needed  
2.4 Enter: Number of guests (maximum), bedrooms, beds, bathrooms  
2.5 Note: Airbnb shows the approximate location publicly; exact address is shared only after booking — this is normal

---

## STEP 3: Amenities (complete ALL applicable)

3.1 Go through every amenity checkbox systematically — do not rush this step  
3.2 Priority amenities to confirm (high search filter impact): WiFi, Kitchen, Washer, Air conditioning, Parking, TV, Dedicated workspace, Self check-in  
3.3 Add any "Safety features" that apply: smoke alarm, CO detector, first aid kit, fire extinguisher  
3.4 Under "Accessibility features" — be accurate; false claims lead to bad-fit guests  
3.5 Note any amenities that are seasonal (e.g., "outdoor pool — open June to September") — state this in the description, not just the amenity checkbox

---

## STEP 4: Photos

4.1 Upload minimum 20 photos (Airbnb recommends 20–35)  
4.2 Order photos: Hero shot first → Living room → Bedroom → Kitchen → Bathroom → Outdoor → Details → Neighbourhood  
4.3 Add a written caption to every single photo — captions appear on hover and help SEO  
4.4 Sample captions:  
   - "Floor-to-ceiling windows flood the living room with morning light"  
   - "Hotel-grade 400-thread-count Egyptian cotton linen on every stay"  
   - "Espresso machine with starter pods provided — Nespresso compatible"  
4.5 Set cover photo (first in order) to highest-impact image — typically the most distinctive room shot or view  
4.6 Preview your listing as a guest and confirm photos display correctly on mobile

---

## STEP 5: Listing Title

5.1 Write a working title draft using the formula from PLATFORM-OPTIMIZATION-GUIDE.md:  
   `[USP] + [Property Type] + [Neighbourhood] w/ [Key Feature]`  
5.2 Count characters — must be ≤50 characters  
5.3 Test 3 title variations; pick the most specific one  
5.4 Example: "Architect Loft · Alfama · Private Roof Terrace" (47 chars)  
5.5 Enter as the listing title

---

## STEP 6: Listing Description

6.1 Write the description in five sections per PLATFORM-OPTIMIZATION-GUIDE.md Section 2  
6.2 **Section 1 — The Hook (2 sentences):** Emotion + unique feature  
6.3 **Section 2 — The Space:** Size, layout, materials, natural light  
6.4 **Section 3 — Key Amenities (5–7 highlights):** What sets you apart  
6.5 **Section 4 — The Neighbourhood:** Why the location matters  
6.6 **Section 5 — Guest Fit:** Who thrives here; who this doesn't work for  
6.7 Total description: 300–500 words. Longer is not better.  
6.8 Proofread twice. Read aloud. Fix any sentence that sounds like it was written by a committee.

---

## STEP 7: Pricing Setup

7.1 Set base/standard nightly rate per PRICING-STRATEGY-PLAYBOOK.md calculations  
7.2 Set cleaning fee (see Pricing Playbook Section 5)  
7.3 Set security deposit amount (recommended: €150–€300)  
7.4 Navigate to: Calendar → Pricing → Custom pricing — set weekend premium (+20–25%)  
7.5 Set "Trip length discounts": 10% for 7+ nights; 15% for 28+ nights  
7.6 Set "Last-minute discount": 10% for check-ins within 3 days  
7.7 Do NOT enable Airbnb Smart Pricing — it consistently underprices properties  
7.8 If using PriceLabs/Wheelhouse: connect via Airbnb Channel Manager API settings

---

## STEP 8: Booking Settings

8.1 Minimum nights: 2 (standard); adjust per season rules in Pricing Playbook  
8.2 Maximum nights: 30 (unless targeting longer stays; some markets restrict 30+ nights)  
8.3 Check-in time: 15:00 (3pm) — gives cleaning team adequate time after late check-outs  
8.4 Check-out time: 11:00 (11am)  
8.5 Advance notice required: "Same day" (maximum flexibility; review manually if concerned)  
8.6 Preparation time: 1 day buffer between bookings recommended for cleaning scheduling  
8.7 Booking window: "All future dates" (do not restrict to 3 or 6 months — unnecessary)  
8.8 Instant Book: Enable with "Guests who meet all your requirements" — significantly increases bookings  
8.9 Instant Book requirements: Government ID + Profile photo + Positive review history (or "No negative reviews")

---

## STEP 9: House Rules

9.1 Enter house rules — see HOUSE-RULES.md for the complete, ready-to-use set  
9.2 In Airbnb, configure: No smoking, No parties, No pets (or adjust to your policy)  
9.3 Set "Quiet hours" if applicable (e.g., 22:00–08:00)  
9.4 Set "Maximum occupants" to match your listed capacity  
9.5 Add any additional rules in the "Additional rules" text field — use the House Rules document

---

## STEP 10: Cancellation Policy

10.1 **New hosts (0 reviews):** Select "Moderate" — 50% refund if cancelled 5+ days before  
10.2 **Established hosts (30+ reviews, 4.8+):** Consider "Firm" — full refund 30+ days before, 50% within 30 days  
10.3 **High-demand properties in peak season:** Block-out peak weeks with non-refundable pricing for locked-in revenue  
10.4 Never select "Flexible" — it attracts cancellations that leave your calendar empty at short notice

---

## STEP 11: Check-in Instructions (Co-Host Access & Smart Lock)

11.1 Navigate to: Listing → Check-in & check-out  
11.2 Select check-in method: "Smart lock" or "Keypad" or "Key lockbox"  
11.3 Write the full check-in instructions (step-by-step, like someone who has never been to the property):  
   - Building entrance instructions  
   - How to find the property door  
   - Access code or smart lock instructions  
   - Where to find the welcome guide inside  
11.4 Test these instructions yourself: walk up to the property with only the instructions on your phone and confirm they are complete  
11.5 Set co-host access if applicable

---

## STEP 12: Saved Messages Setup

12.1 Navigate to: Inbox → Saved Messages → Create New  
12.2 Create all 14 saved message templates from Section 04 of this kit  
12.3 Name each message with an emoji prefix for quick identification in the inbox:  
   - "✅ Booking Confirmed"  
   - "📋 Pre-Arrival Info"  
   - "🔑 Check-In Instructions"  
   - "👋 Mid-Stay Check-In"  
   - "🧳 Check-Out Reminder"  
   - "🙏 Post-Checkout Thanks"  
   - "⭐ Review Request"  
   - "🔧 Issue Response"  
   - "🔇 Noise Complaint"  
   - "💬 Inquiry Response"  
   - "🚫 Soft Decline"  
   - "🏠 Long-Stay Welcome"  
   - "🌟 5-Star Review Response"  
   - "📝 Negative Review Response"  
12.4 Personalise each template with your property-specific details before saving

---

## STEP 13: Publish & Monitor

13.1 Preview your listing as a guest (Airbnb has a "Preview" button before publishing)  
13.2 Check listing on mobile — most guests browse on phone  
13.3 Confirm all photos display correctly in order  
13.4 Click "Publish" — your listing is live  
13.5 Airbnb provides a "new listing boost" for approximately 14–21 days — monitor your views daily  
13.6 If no booking within 72 hours: check price vs. competitors (see Pricing Playbook), and verify title and photos are competitive  
13.7 Your first goal: first booking within 7 days. Your first 5 reviews are your most important leverage
