## WHAT THIS PRODUCT IS

The Airbnb Host Starter Kit is an operating system for short-term rental hosts. It is not a PDF of tips. It is not a collection of generic templates. It is a complete, specific, numbered system that a host can run a property on from the first booking forward.

**59 files. 8 folders. Every file contains usable content.**

No placeholders that remain unfilled after initial setup. No Lorem Ipsum. No "insert your content here" instructions that leave the buyer doing the actual work.

---

## WHO THIS IS FOR

Hosts managing 1–3 properties who are:
- Launching for the first time and want to start correctly
- Already hosting and getting 4-star reviews without understanding why
- Currently spending 3+ hours per booking on messages, checklists, and admin they have to recreate each time
- Targeting Superhost status within 6–12 months

This kit is not for hosts managing 10+ properties (the Multi-Property Management Kit addresses that use case) or for property managers running STR portfolios professionally. It is calibrated for an owner-operator with 1–3 properties in a mid-tier European market.

## HOW TO SET UP

**Day 1 (30 minutes):**
1. Read `00-QUICK-START-GUIDE.md` — 5 steps, no more than 30 minutes
2. Load 14 message templates into Airbnb Saved Messages
3. Build TAB-01 (Revenue Tracker) in Google Sheets

**Days 2–7 (1–2 hours total):**
- Build the remaining 6 tracking tabs
- Add 10 recurring SOPs to your task system
- Set up the Notion workspace (optional but recommended)

**Full setup time:** 4–6 hours spread over the first week.
**Time saved per booking once operational:** 45–90 minutes.

## FILE FORMAT

All files are in Markdown (.md) format.

**To use in Notion:** Copy-paste the file content into a new Notion page. Markdown headings (#, ##, ###) become Notion headings. Tables and bullet lists render correctly.

**To use in Google Docs:** Open a new document → Insert → Upload file → select the .md file. Or copy-paste content and apply styles manually.

**To use in Microsoft Word:** Copy-paste content. Headings and tables will need manual formatting.

**To use as-is:** Any text editor reads .md files correctly. The content is the same regardless of where you open it.
