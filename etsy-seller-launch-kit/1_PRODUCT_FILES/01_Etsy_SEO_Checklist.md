## PART 1 — TITLE OPTIMIZATION

### The Rules
- [ ] Title is under **140 characters** (Etsy's limit)
- [ ] **Primary keyword appears in the first 40 characters** (most important — this is what shows in search)
- [ ] Title reads naturally — not just a string of keywords
- [ ] No ALL CAPS words (looks spammy, hurts conversions)
- [ ] No special characters (★, ✓, etc.) — Etsy ignores them
- [ ] No repetition of the same word more than twice

### The Structure
Use this formula:
`[Primary Keyword] | [Secondary Keyword] | [Feature or Benefit] | [Use Case]`

Example:
`Watercolor Wedding Invitation Template | Editable Canva | Dusty Blue Floral | Instant Download`

## PART 2 — TAGS (All 13 Must Be Used)

### The Rules
- [ ] All **13 tag slots used** — leaving tags empty is leaving traffic on the table
- [ ] Each tag is **1–3 words** (multi-word tags target longer searches)
- [ ] Tags **do NOT repeat** words already in the title — Etsy reads title + tags together
- [ ] Tags match **actual buyer search behavior** (what would a buyer type, not what you'd call it)
- [ ] At least **2–3 long-tail tags** (3 words, specific: "digital planner 2025" not just "planner")
- [ ] At least **1 occasion tag** if applicable ("wedding gift," "birthday gift," "teacher gift")
- [ ] At least **1 style/aesthetic tag** ("boho," "minimalist," "cottagecore," "dark academia")
- [ ] At least **1 recipient tag** if applicable ("for her," "for him," "for mom")

## PART 3 — DESCRIPTION SEO

- [ ] **First 160 characters** contain the primary keyword (this is the meta description Google sees)
- [ ] Description reads as a buyer would want to read it — benefits first, details second
- [ ] Primary keyword appears **2–3 times** naturally throughout
- [ ] Secondary keywords appear at least once each
- [ ] Description answers these questions:
  - [ ] What is this? (product type)
  - [ ] What do I get? (deliverables)
  - [ ] Who is it for? (buyer identity)
  - [ ] How do I use it? (brief instructions)
  - [ ] What format is it in? (file type, software needed)
  - [ ] How do I get it? (download process)
- [ ] Bullet points or sections used (easier to scan)
- [ ] CTA (call to action) present: "Add to cart," "Message with questions"

---

## PART 4 — LISTING PHOTOS

- [ ] **First photo** is clean, high-contrast, and communicates what the product is in **1 second**
- [ ] First photo is **2700×2025px** (Etsy's recommended size for full quality)
- [ ] No blurry, dark, or pixelated photos
- [ ] Multiple angles or uses shown (lifestyle + product + detail)
- [ ] Text overlay is readable at thumbnail size
- [ ] No watermarks on product mockups
- [ ] All 10 photo slots used (more photos = more trust)
- [ ] Photos optimized for **mobile** (most Etsy browsing is mobile — test at thumbnail size)

---

## PART 5 — PRICING

- [ ] Price researched against **5–10 competitors** for similar products
- [ ] Shipping cost is **$0 for digital items** (Etsy auto-sets this, but verify)
- [ ] **Etsy fees factored** into price (listing $0.20 + 6.5% transaction + 3% + $0.25 payment processing)
- [ ] Price is not rounded to a "nice" number — $14.97 outperforms $15.00 in click-through tests

---

## PART 6 — LISTING DETAILS

- [ ] **Category** is correct and as specific as possible
- [ ] **Attributes** fully filled in (color, occasion, style, etc.)
- [ ] **Production partner** declared if using a print-on-demand service
- [ ] **Renewal** set to automatic
- [ ] **Digital delivery** checked and correct download file attached
- [ ] **Quantity** set to 999 (or highest allowed for digital listings)

---

## PART 7 — SHOP-LEVEL SEO FACTORS

- [ ] Shop **About section** contains your primary niche keywords
- [ ] Shop **title** (the tagline under your name) contains keywords
- [ ] Shop **announcement** is active and up to date
- [ ] All **shop sections** have keyword-rich names ("Wedding Templates" not "Collection 1")
- [ ] Shop **policies** fully filled in
- [ ] **Free shipping guarantee** enabled if applicable (boosts rankings)

---

## PART 8 — ALGORITHM QUALITY SIGNALS

These factors influence your ranking beyond keywords:

- [ ] **Listing has been shared** on Pinterest, Instagram, or other social
- [ ] **Conversion rate** is healthy — if people click but don't buy, update photos and description
- [ ] **Review score** is above 4.5 — low reviews suppress ranking
- [ ] **Shop has recent sales** — Etsy rewards active shops
- [ ] **Customer messages** answered within 24 hours
- [ ] **Shipping time** set accurately (for physical products)
