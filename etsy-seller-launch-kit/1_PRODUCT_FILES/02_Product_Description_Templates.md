## UNIVERSAL DESCRIPTION DO'S AND DON'TS

**DO:**
✓ Start with the buyer's desire or problem — not your product's features
✓ Use bullet points for scannability
✓ Include your primary keyword in the first 160 characters
✓ Answer the most common questions before they have to ask
✓ State the file format clearly — "PNG" not "digital file"
✓ End with a CTA and how to contact you

**DON'T:**
✗ Start with "I" or your shop name
✗ Use all-caps paragraphs
✗ Include external links (Etsy removes them)
✗ Copy descriptions from competitors
✗ Promise things you can't deliver (instant results, guaranteed income, etc.)
✗ Forget to mention what software is needed to open the files
