## HOW TO USE THIS TRACKER

**Option 1 — Google Sheets (recommended):**
Copy this template into Google Sheets. Use one tab per month. Add formulas for automatic totals.

**Option 2 — Printed:**
Print the monthly pages and fill in by hand. Run totals at end of month.

**When to update:** After each sale (daily) or weekly in a batch.

## ETSY STATS QUICK REFERENCE

**Where to find your numbers:**

| Data | Location in Etsy |
|---|---|
| Monthly revenue | Shop Manager → Stats → Revenue |
| Orders | Shop Manager → Orders |
| Conversion rate | Shop Manager → Stats → Listings |
| Top keywords | Shop Manager → Stats → Traffic Sources |
| Views per listing | Shop Manager → Stats → Listings |
| Review score | Shop Manager → Reviews |

**Export tip:** Etsy allows CSV export of your orders. Go to Shop Manager → Orders → Download CSV. Import into Google Sheets for more powerful analysis.
