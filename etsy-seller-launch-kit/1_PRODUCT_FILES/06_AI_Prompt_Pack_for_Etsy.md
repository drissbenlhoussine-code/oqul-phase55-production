## SECTION 1 — TITLE & TAG PROMPTS (10 prompts)

**Prompt 1 — Generate title options**
```
I sell [product type] on Etsy. My primary keyword is "[keyword]". Write 5 different Etsy listing title options, each under 140 characters. Each title should include the primary keyword in the first 40 characters, plus secondary keywords like [keyword 2] and [keyword 3]. Make them sound natural, not like keyword spam. Format: one title per line.
```

**Prompt 2 — Generate all 13 tags**
```
I'm listing "[product name]" on Etsy. My title is: "[your title]". Generate 13 Etsy tags for this listing. Tags should NOT repeat words already in the title (Etsy reads them together). Include a mix of: 3 core product tags, 2 style/aesthetic tags, 2 occasion tags, 2 long-tail (3-word) tags, 2 recipient tags ("for her," "for teacher," etc.), and 2 trending or seasonal tags. Output as a numbered list of single tags (1–3 words each).
```

**Prompt 3 — Improve an existing title**
```
Here is my current Etsy listing title: "[current title]"
The product is: [describe product]
My target buyer is: [describe buyer]
Please rewrite this title to be more SEO-optimized. The primary keyword "[keyword]" must appear in the first 40 characters. Keep it under 140 characters and make it read naturally.
```

**Prompt 4 — Find long-tail keyword variations**
```
I sell [product type] on Etsy. Give me 20 long-tail keyword variations (2–4 words each) that buyers might search when looking for this product. Focus on specific use cases, occasions, styles, and recipient types. Format as a numbered list.
```

**Prompt 5 — Generate niche keywords by buyer type**
```
My Etsy product is [product]. Generate 5 keyword ideas for each of these buyer types: [buyer type 1], [buyer type 2], [buyer type 3]. I want keywords that reflect how each type of buyer actually searches, not generic terms.
```

**Prompt 6 — Seasonal keyword refresh**
```
My Etsy shop sells [product type]. Give me the top 5 Etsy search keywords I should add to my listings for [month/season]. Include specific holiday, occasion, and trending search terms relevant to this time of year.
```

**Prompt 7 — Competitor tag analysis**
```
Here are the tags from a top-selling Etsy competitor in my niche: [paste tags here]. My product is [describe it]. Tell me: which of these tags are likely high-volume, which are low-competition, and suggest 5 tags I should add to my own listing that this competitor is NOT using.
```

**Prompt 8 — Pinterest keyword research**
```
I sell [product] on Etsy. Write 10 Pinterest pin titles and descriptions I can use to drive traffic to my Etsy listings. Each pin should target a different keyword variation. Include the keyword naturally in both the title and first line of the description.
```

**Prompt 9 — Etsy vs. Google SEO comparison**
```
I want to rank for "[keyword]" on both Etsy and Google. Explain the top 3 differences in how I should optimize my Etsy listing title and description for each platform. Then write one title that works for both.
```

**Prompt 10 — A/B test title options**
```
I want to A/B test two Etsy listing titles for [product]. My current title is: "[current title]". Write an alternative title that targets a different buyer intent or uses a different primary keyword. Explain which one you'd expect to perform better and why.
```

## SECTION 2 — PRODUCT DESCRIPTION PROMPTS (10 prompts)

**Prompt 11 — Write a full description from scratch**
```
Write an Etsy product description for [product name].

Product details:
- What it is: [description]
- What's included: [list]
- File format: [format]
- Who it's for: [buyer types]
- Primary keyword: "[keyword]"
- Secondary keywords: "[keyword 2]", "[keyword 3]"

Requirements:
- Start with the primary keyword in the first 160 characters
- Use bullet points for the "what's included" section
- Include a FAQ section with 3 common questions
- End with a call to action
- DO NOT start with "I" or the shop name
- Total length: 300–500 words
```

**Prompt 12 — Rewrite a weak description**
```
Here is my current Etsy listing description: [paste description]

Please rewrite it to:
1. Open with the buyer's desire, not product features
2. Include my primary keyword "[keyword]" in the first 160 characters and 2–3 more times naturally
3. Be more scannable (use bullet points, not dense paragraphs)
4. Add a FAQ section addressing: [question 1], [question 2]
5. End with a stronger call to action
```

**Prompt 13 — Hook sentence options**
```
Write 10 different opening sentences for an Etsy listing for [product]. Each should address a different buyer desire or pain point. They should be 1–2 sentences, conversational, and make the buyer think "yes, that's me." Do NOT start any with "Are you..." or "Do you..."
```

**Prompt 14 — FAQ section generator**
```
I sell [product type] on Etsy. Generate a FAQ section with 5 questions and answers that buyers commonly have before purchasing. Focus on questions about: format/compatibility, how to use the product, refund policy, customization options, and printing (if applicable). Write the answers from the perspective of a helpful, professional shop owner.
```

**Prompt 15 — Bundle description**
```
Write an Etsy product description for a bundle of [X items]. The bundle includes: [list items]. The primary benefit of buying the bundle (vs. individual items) is [benefit — savings / convenience / cohesion]. Price: $[X] vs. $[X] individually. Target buyer: [buyer type]. Primary keyword: "[keyword]".
```

**Prompt 16 — Digital download description (any product)**
```
Write an Etsy description for a digital download product. Product: [describe it]. What buyer gets: [list]. Software needed: [software]. Primary keyword: "[keyword]". Emphasize: instant download, no shipping wait, editable/customizable. Format with headers and bullet points. Under 400 words.
```

**Prompt 17 — Product description for international buyers**
```
My Etsy shop sells [product] and I get many international buyers. Rewrite my current description to be: clearer for non-native English speakers, explicit about digital delivery (no shipping), and include my primary keyword "[keyword]" in a way that reads naturally across dialects. Current description: [paste]
```

**Prompt 18 — Mobile-optimized description**
```
Most Etsy browsing is on mobile where buyers skim quickly. Take this description and reformat it for mobile: shorter sentences, more line breaks, bold key phrases, and the most important information in the first 3 lines. Current description: [paste]
```

**Prompt 19 — Description for seasonal listing**
```
I have a year-round product [describe it] that I want to promote for [holiday/season]. Rewrite the description to emphasize the seasonal use case and include seasonal keywords like "[keyword]", "[keyword 2]". Keep the core product info but lead with the seasonal angle.
```

**Prompt 20 — Value proposition paragraph**
```
Write a 3–4 sentence paragraph explaining why my [product] is worth buying vs. free alternatives or making it from scratch. Focus on time saved, professional quality, and the specific outcome the buyer gets. Product: [describe]. Buyer: [describe]. Don't use generic phrases like "high quality" or "great value."
```

## SECTION 3 — CUSTOMER MESSAGES & REVIEWS (10 prompts)

**Prompt 21 — Reply to a 5-star review**
```
A customer left this 5-star review on my Etsy shop: "[review text]". Write a warm, genuine 2–3 sentence public reply that: thanks them specifically, references something they mentioned, and subtly mentions my shop type for SEO. Don't be generic.
```

**Prompt 22 — Reply to a 3-star review**
```
A customer left this review: "[review text]" with [X] stars. Write a professional, non-defensive 3–4 sentence public response that: acknowledges their feedback, explains the situation (if applicable), offers to help, and shows future buyers I take quality seriously.
```

**Prompt 23 — Reply to a 1-star review**
```
I received this 1-star review: "[review text]". Write a calm, professional public response that: doesn't argue or sound defensive, acknowledges the frustration, explains what happened (if there's a valid reason), and invites them to contact me to resolve it. My response will be read by future buyers — it should show I'm a responsive, fair seller.
```

**Prompt 24 — Review request message**
```
Write 3 different post-purchase Etsy message templates asking for a review. All should be: under 5 sentences, warm but not pushy, mention that reviews help small sellers, and tell the buyer exactly where to leave the review. Vary the tone: one casual, one professional, one heartfelt.
```

**Prompt 25 — Response to "I can't open my file"**
```
A customer messaged me: "I downloaded my file but can't open it." Write a helpful, clear response that: stays calm, asks the 3 most important diagnostic questions (operating system, software they're using, error message they see), and provides my top 2 troubleshooting steps. Keep it under 150 words.
```

**Prompt 26 — Response to refund request for a digital product**
```
A customer is requesting a refund saying the product "didn't work as expected" for a digital download (no technical issue — they just didn't like it). Write a professional response that: explains my no-refund policy for digital downloads kindly, offers an alternative solution (help using it / different version), and doesn't sound defensive or dismissive.
```

**Prompt 27 — Custom order response**
```
A customer messaged asking: "[custom request]". I [can / cannot] fulfill this request. Write a response that: [If yes:] clearly explains what I can do, the price, and the timeline. [If no:] politely declines, explains why, and suggests an alternative if possible. Keep under 100 words.
```

**Prompt 28 — "Where is my order?" response**
```
A customer is asking where their digital download is. Write a short, helpful response explaining: (1) digital downloads are instant, (2) how to find it (Etsy account → Purchases → Download), (3) check spam folder for the email, (4) offer to help directly if they still can't find it.
```

**Prompt 29 — Follow-up message to first-time buyers**
```
Write a friendly Etsy message to send to a first-time buyer after they purchase. It should: thank them for their first purchase, give a helpful tip for using the product, invite them to message with questions, and softly mention they can save 15% with the coupon code [CODE] on their next order. Under 100 words.
```

**Prompt 30 — Abandoned cart follow-up message**
```
I want to send a follow-up message to a potential buyer who added my [product] to their cart but didn't purchase. Write a soft, non-pushy message that: reminds them the item is still available, mentions the main benefit, and offers a limited-time 10% discount code [CODE]. Under 75 words.
```
