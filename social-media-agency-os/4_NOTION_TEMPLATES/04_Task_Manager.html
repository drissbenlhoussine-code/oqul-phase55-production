Setup Guide — Recreate in Notion
📐 How to Build This Task Manager in Notion (Step-by-Step)
1

Create the Tasks Database

In Notion, create a new Full-page database called 📋 Tasks. Switch to Table view. This will be your master task list — every task for every client goes here.

2

Add Required Properties

Add these properties to your database: Task Name (Title) · Client (Relation → Clients DB) · Category (Select: Content / Client / Reporting / Admin / Sales) · Assignee (Person) · Priority (Select: 🔴 High / 🟡 Medium / 🟢 Low) · Status (Select: ⬜ Inbox / ▶ In Progress / 👁 In Review / ✅ Done / ⛔ Blocked) · Due Date (Date) · Sprint (Select: Sprint 1, Sprint 2…) · Notes (Text)

3

Build the Kanban Board View

Add a new Board view → Group by Status. You'll get 5 columns: Inbox / In Progress / In Review / Done / Blocked. This is your main working view — drag cards between columns to update status.

4

Create Filtered Table Views

Add these filtered views: Today (Table, filter: Due Date = Today) · This Week (Table, filter: Due Date = Next 7 days) · My Tasks (Table, filter: Assignee = Me) · By Client (Table, group by Client) · Overdue (Table, filter: Due Date < Today AND Status ≠ Done)

5

Set Up Recurring Checklists

Create a second database called 🔁 Recurring Checklists with properties: Task (Title) · Frequency (Select: Daily / Weekly / Monthly) · Done This Period (Checkbox) · Owner (Person). Reset checkboxes at the start of each period. Alternatively, use the Notion Recurring Tasks template from the Notion template gallery.

6

Sprint Planning Setup

Add a Sprint Select property (Sprint 1, Sprint 2…). Create a view filtered to the current sprint only. Each sprint = 2 weeks. At sprint start: assign tasks to sprint → at sprint end: review + roll over incomplete tasks to next sprint. Add a Story Points Number property to estimate task effort (1=easy, 3=medium, 5=hard).

7

Connect to Other Databases

Use Relation properties to link: Tasks → CRM Database (per client) and Tasks → Content Calendar (for content tasks). This lets you see all tasks for a client in their CRM profile, and all content creation tasks in the content calendar.
